# ЛР1. Декомпозиція сервісних систем та Domain Discovery

Протокол: [ЛР1_SOA_КН-61мп_Заєць.docx](ЛР1_SOA_КН-61мп_Заєць.docx). Варіант 4 — хмарна інформаційна система для календаря користувача.

Робота проєктна: за завданням ЛР1 визначено межі сервісів і їхню взаємодію, програмного коду для розгортання немає.
Спроєктовані тут сервіси реалізовано та розгортаються в [lab2](../lab2) і [lab3](../lab3).

## Результати проєктування

| Розділ протоколу | Зміст |
|---|---|
| Моделювання за подіями (Event Storming) | команди, доменні події та правила для створення, участі, нагадування, перенесення й скасування |
| Обмежені контексти | планування календаря, участь у подіях, нагадування та сповіщення, зовнішня синхронізація (необов’язкова) |
| Доменні моделі | агрегати «Календар», «Подія», «Запрошення»; об’єкти значення; інваріанти; загальна мова |
| Контракти | REST-операції сервісів і конверт інтеграційної події `EventCreated.v1` |
| План | ЛР2 — мікросервіси, ЛР3 — Outbox і SAGA, ЛР4 — виявлення сервісів, ЛР5 — безпека API, ЛР6 — спостережуваність |
